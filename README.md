# CloudWise AZ-900 Coach

An unofficial AZ-900 study tool with original practice questions. It is not affiliated with Microsoft.

## Run locally

1. Open this folder in VS Code.
2. In the project terminal, run `npm install` once.
3. Run `npm run dev` and open the local address Vite prints.

## Learning flow

The app includes Learn → Test → Repair → Retest, browser-local progress, and a My Learning Gaps section. The reviewed remediation pairs include Service Health vs Resource Health, Azure Policy vs RBAC, and Azure Monitor vs Advisor. A correct follow-up records a corrected attempt; it does not label a whole topic mastered.
